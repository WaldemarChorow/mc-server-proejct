## Quickstart

1. **Create and enter your project directory:**
   ```bash
   mkdir mc-server
   cd mc-server

```

2. **Create a `README.md` file:**
For now, a project title and description will suffice.
3. **Set up Git and GitHub:**
* Initialize local repository:
```bash
git init

```

* Stage the README file:
```bash
git add README.md

```

* Make your first commit:
```bash
git commit -m "Initialize MC-Server project and add README.md"

```

* Create a repository on your GitHub account, then link and push:
```bash
git remote add origin [https://github.com/Example/mc-server-project.git](https://github.com/Example/mc-server-project.git)
git branch -M main
git push -u origin main

```
