# Minecraft Server Initialisation 

## This project show the steps for the initializantion for a own server. 

## Quickstart

    1. Go in your Direction iánd give him the name "mc-server"
    2. Creat a README.md. 
        For now, a project title and description will suffice.
    3. Carry out the GitHub steps
        1. <>git init</>
        2. <>git add ./README.md</>
        3. take your first commit 
            <>git commit -m "Initilized Project MC-Server and add README.md"</>
        4. Creat a reposetory on you GitHub Account
        5. Remote to Github Repo
            <>git remote add origin https://github.com/Example/mc-server-proejct.git</>
        6. Push the commit to github Repo
            git push -u origin main
    4. Creat a DOCKERFILE
    5. Creat a .gitignore file
    6. Creat compose.yaml file
